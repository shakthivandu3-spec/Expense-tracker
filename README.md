# 💰 Expense Tracker Dashboard

A responsive and user-friendly expense tracker dashboard built using HTML, CSS, and JavaScript.

## 📌 About the Project

The Expense Tracker Dashboard helps users manage their personal finances by tracking income and expenses in one place.

Users can add transactions, categorize expenses, view their financial summary, and delete transactions. Transaction data is stored using browser LocalStorage so it remains available after refreshing the page.

## ✨ Features

- Add income and expense transactions
- Categorize transactions
- Calculate total income
- Calculate total expenses
- Calculate current balance
- Delete transactions
- Store data using LocalStorage
- Responsive dashboard design
- Expense analytics
- Modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git & GitHub
